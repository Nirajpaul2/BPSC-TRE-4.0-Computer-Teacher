📑 What is the syllabus for BPSC TRE 4.0 Computer Science (PGT)? ▼

The BPSC TRE 4.0 CS (PGT 11–12) syllabus is strictly aligned with NCERT Class 11 and Class 12 Computer Science (Subject Code 083), organized into 12 core units:

  1. Computer Systems & Organization (Architecture, Memory, Microprocessors)
  2. Computational Thinking & Python Programming (Flow of control, Functions, Recursion)
  3. Advanced Python & Data Structures (Strings, Lists, Tuples, Dictionaries, Stacks, Queues)
  4. Database Management Systems & Relational Algebra
  5. Structured Query Language (SQL - DDL, DML, Aggregate Functions, Joins)
  6. Computer Networks & Network Topologies (OSI/TCP-IP models, Protocol Suite)
  7. Data Communication & Transmission Media
  8. Cyber Safety, Security & IT Ethics (Indian IT Act, Cyber Crime)
  9. Boolean Algebra & Logic Circuits (K-Maps, Logic Gates)
  10. Web Concepts & Full-Stack Fundamentals (HTML5, CSS, Client-Server Architecture)
  11. Operating Systems Fundamentals (Process scheduling, Memory management, Deadlocks)
  12. Software Engineering & Emerging Trends (SDLC, AI, Cloud, IoT)
